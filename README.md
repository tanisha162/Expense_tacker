## 📌 Project Overview
**ExpenseTracker** is a clean, full-stack Django web application engineered to give users granular control over their daily expenses, income streams, and monthly budget forecasts through relational database models and interactive spending visualizers.

---

## ✨ Features
- **User Authentication:** Secure session-based signup, login, and profile management.
- **Categorized Ledger:** Add, edit, filter, and delete expenses categorized by food, travel, utilities, and investments.
- **Analytical Reports:** Monthly expenditure totals, category percentage breakdowns, and spending trends.
- **Data Portability:** One-click CSV export of transaction histories for external analysis.
- **Cloud Ready:** Structured with `Procfile` and `build.sh` for instant deployment on Render or Heroku.

## 🚀 Local Deployment

```bash
git clone https://github.com/tanisha162/Expense_tacker.git
cd Expense_tacker

python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```
